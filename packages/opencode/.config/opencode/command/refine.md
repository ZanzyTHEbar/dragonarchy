# `/refine`

Improve the previous answer or artifact through deliberate variation and specific critique.

Input or target: $ARGUMENTS

1. Produce three materially different solution frames or drafts when variation can improve the result.
2. Review each for logic, clarity, evidence, risk, audience fit, and technical accuracy.
3. Select the strongest foundation instead of averaging weak ideas.
4. Rewrite one final result that is cleaner and more useful than any draft.
5. Briefly identify the decisive improvements when that helps the user.

Keep critique testable and substantive. Do not expose hidden chain-of-thought or disguise trivial paraphrases as independent drafts.
