# `/save`

Create a factual, resume-friendly checkpoint for the current task.

1. Restate the active goal.
2. Summarize concrete progress already made.
3. Name blockers, open assumptions, unresolved risks, and external dependencies.
4. State the single best next step.
5. Include key files, decisions, and validation results only when they help recovery.

Use the todo list as the source of truth for in-flight work. Do not turn this into a changelog or a vague promise to continue later.
